# Rifat Idea

Build a professional, modern and fully responsive influencer marketing marketplace named "BrandLinks" for Bangladesh.

Tagline: "Brands Meet Influencers."

The platform connects businesses with influencers and content creators across Facebook, Instagram, YouTube, TikTok and other social media platforms.

DESIGN:

- Premium modern SaaS design

- Blue and white color palette

- Clean typography and professional layout

- Mobile-first responsive design

- Bengali and English language support

- All prices in Bangladeshi Taka (BDT)

USER ROLES:

1. Business/Brand

2. Influencer/Creator

3. Admin

PAGES:

1. Homepage with hero section, search bar and featured influencers.

2. Influencer directory with filters for platform, followers, location, niche and budget.

3. Influencer profile with bio, social links, audience details and packages.

4. Business registration and dashboard.

5. Creator registration and dashboard.

6. Campaign creation and booking request system.

7. Booking status and campaign tracking.

8. Messaging interface.

9. Creator earnings and platform commission dashboard.

10. Admin dashboard for user verification, bookings, payments and disputes.

11. About, Help, Terms and Privacy pages.

FUNCTIONAL REQUIREMENTS:

- Secure authentication

- Role-based access

- Supabase database integration

- Influencer verification workflow

- Booking request, accept and decline

- Admin-managed payment verification for MVP

- Configurable platform commission

- Reviews and ratings

- Bengali/English language switch

IMPORTANT:

Start by building the complete frontend and a clear database structure. Use realistic sample data for the prototype. Do not create fake payment processing. Do not expose private user information. Prepare secure Supabase Row Level Security policies before production use.

Build a functional MVP, not just a static landing page.
